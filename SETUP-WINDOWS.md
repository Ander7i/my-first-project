# Подключение бота на Windows Server

Инструкция для VPS с Windows Server. Если у вас Linux — смотрите
[SETUP.md](SETUP.md), там всё иначе.

Отличия от Linux: подключение через удалённый рабочий стол вместо SSH,
Python ставится установщиком, автозапуск — через планировщик задач.

---

## Что понадобится

- Данные сервера из панели хостинга: IP, порт, логин, пароль.
  В Lizax они на карточке сервера: строка `IPV4` вида
  `91.108.239.5:55371`, `ЛОГИН` и `ROOT-ПАРОЛЬ`.
- Приложение для удалённого рабочего стола.

---

## Шаг 1. Подключиться к серверу

Windows Server управляется не через SSH, а через **RDP** — удалённый
рабочий стол. Termius для этого не подходит.

**С айфона или айпада:** поставьте из App Store приложение
**Windows App** от Microsoft (раньше называлось Microsoft Remote
Desktop). Внутри: **+** → **Add PC**.

**С компьютера на Windows:** нажмите `Win+R`, введите `mstsc`.

**С Mac:** то же приложение **Windows App** из Mac App Store.

Заполните:

| Поле | Что вписать |
|---|---|
| PC name / Компьютер | `IP:порт` целиком, например `91.108.239.5:55371` |
| Username / Пользователь | логин из панели, например `Admin` |
| Password / Пароль | пароль из панели |

> В RDP, в отличие от SSH, адрес и порт пишутся **вместе через
> двоеточие** — так и задумано.

Появится предупреждение о сертификате — нажмите **Continue** или
**Подключиться всё равно**. Откроется рабочий стол Windows.

---

## Шаг 2. Поставить Python

На сервере откройте браузер (Edge есть в меню «Пуск»).

1. Зайдите на **python.org/downloads/windows**
2. Скачайте **Windows installer (64-bit)** любой версии **3.10 и выше**
3. Запустите установщик

**Важно при установке:** внизу первого экрана поставьте галочку
**«Add python.exe to PATH»**. Без неё команды не будут работать, и
придётся переустанавливать.

Затем нажмите **Install Now** и дождитесь конца.

> Если Edge не даёт скачивать из-за «Enhanced Security Configuration»,
> откройте **Server Manager** → **Local Server** → выключите
> **IE Enhanced Security Configuration**.

### Проверка

Откройте **PowerShell**: правой кнопкой по «Пуск» → **Windows
PowerShell**. Введите:

```powershell
python --version
```

Должна появиться версия вида `Python 3.12.7`. Если пишет, что команда не
найдена — установщик ставился без галочки PATH, переустановите.

---

## Шаг 3. Скачать бота

Git на Windows ставить не нужно — проще скачать архивом.

1. В браузере откройте
   **github.com/Ander7i/my-first-project**
2. Зелёная кнопка **Code** → **Download ZIP**
3. Откройте папку «Загрузки», правой кнопкой по архиву →
   **Извлечь всё**
4. Укажите путь `C:\bot` и нажмите **Извлечь**

После распаковки файлы могут оказаться во вложенной папке вроде
`C:\bot\my-first-project-claude-telegram-secret-shopper-bot-rwn5g1`.
Это нормально — запомните этот путь, он понадобится дальше. Можете
переименовать папку в `C:\bot\app`, чтобы было короче.

Проверьте, что внутри лежат `requirements.txt` и папка `bot`.

---

## Шаг 4. Установить зависимости

В PowerShell перейдите в папку с ботом и создайте окружение. Замените
путь на свой, если он отличается:

```powershell
cd C:\bot\app
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Последняя команда качает библиотеки, это займёт минуту-две.

---

## Шаг 5. Вписать токен

Скопируйте файл настроек и откройте его в Блокноте:

```powershell
copy .env.example .env
notepad .env
```

В открывшемся окне:

- в строке `BOT_TOKEN=` впишите свой токен от @BotFather
- в строке `ADMIN_IDS=` пока оставьте `1`

**Сохраните через Файл → Сохранить как**, и в поле **Кодировка**
выберите **UTF-8**. Это важно: в файле есть русские комментарии, и при
сохранении в другой кодировке бот не прочитает настройки.

---

## Шаг 6. Первый запуск и свой ID

```powershell
.venv\Scripts\python.exe -m bot
```

Дождитесь строки `Бот @ваш_бот запущен`.

В Телеграме найдите своего бота, нажмите **Start** и отправьте `/myid`.
Бот ответит числом.

Остановите бота в PowerShell: **Ctrl+C**.

Откройте настройки снова и впишите полученное число в `ADMIN_IDS`, а
свой ник — в `SUPPORT_CONTACT`:

```powershell
notepad .env
```

Снова сохраните в UTF-8. Запустите бота и отправьте ему `/admin` —
должна появиться панель с цифрами.

---

## Шаг 7. Группа

Эти шаги одинаковы для любой системы, они делаются в Телеграме:

1. Добавьте бота в группу **администратором** с правом отправки
   сообщений
2. Напишите в группе `/chatid`, получите число с минусом
3. Впишите его в `GROUP_CHAT_ID` в `.env`
4. В @BotFather: `/setprivacy` → ваш бот → **Disable**
5. **Удалите бота из группы и добавьте заново** — иначе настройка не
   применится

Подробности с пояснениями — в [SETUP.md](SETUP.md), шаги 5–7.

## Шаг 8. Автозапуск

В Windows нет `systemd`. Сделаем через планировщик задач: бот будет
подниматься при старте сервера и перезапускаться, если упадёт.

### Создайте файл запуска

```powershell
notepad C:\bot\start-bot.bat
```

Блокнот спросит, создавать ли файл — согласитесь. Вставьте внутрь,
заменив путь на свой:

```bat
@echo off
set PYTHONUTF8=1
cd /d C:\bot\app
:loop
.venv\Scripts\python.exe -m bot
echo Бот остановился, перезапуск через 10 секунд...
timeout /t 10 /nobreak
goto loop
```

Цикл `:loop` и есть замена автоперезапуску: если бот упадёт, через 10
секунд он поднимется снова.

Сохраните **в UTF-8**.

### Зарегистрируйте задачу

В PowerShell **от имени администратора** (правой кнопкой по «Пуск» →
**Windows PowerShell (администратор)**):

```powershell
schtasks /create /tn "ShopperBot" /tr "C:\bot\start-bot.bat" /sc onstart /ru SYSTEM /rl HIGHEST /f
```

Запустите задачу прямо сейчас, не дожидаясь перезагрузки:

```powershell
schtasks /run /tn "ShopperBot"
```

Проверьте, что работает:

```powershell
schtasks /query /tn "ShopperBot"
```

В колонке статуса должно быть **Running**.

### Команды на будущее

| Что нужно | Команда |
|---|---|
| Остановить бота | `schtasks /end /tn "ShopperBot"` |
| Запустить снова | `schtasks /run /tn "ShopperBot"` |
| После правки `.env` | остановить, затем запустить |
| Удалить задачу | `schtasks /delete /tn "ShopperBot" /f` |

> **Правили `.env` — перезапустите задачу.** Бот читает настройки только
> при старте.

## Шаг 9. Опубликовать набор

Отправьте боту в личку `/post` — он опубликует объявление в группе.

Перед этим пройдите путь сами: заполните анкету со своего аккаунта,
создайте тестовое задание, возьмите его и сдайте отчёт. В группе уже
есть люди, и объявление они увидят сразу.

## Если не работает

**`python` не найден**

Установщик ставился без галочки «Add python.exe to PATH».
Переустановите Python, отметив её. Либо используйте полный путь:
`C:\Users\Admin\AppData\Local\Programs\Python\Python312\python.exe`

**`Telegram отклонил токен`**

Токен скопирован не полностью или файл сохранён не в UTF-8. Откройте
`.env` в Блокноте и проверьте строку `BOT_TOKEN=`.

**Ошибка кодировки при запуске**

В `.bat` должна быть строка `set PYTHONUTF8=1`. Если запускаете вручную
из PowerShell, выполните сначала:

```powershell
$env:PYTHONUTF8=1
```

**Бот не отвечает после перезагрузки сервера**

Проверьте задачу: `schtasks /query /tn "ShopperBot"`. Если её нет —
создайте заново командой из шага 8.

**`.venv\Scripts\python.exe` не найден**

Не создалось окружение. Повторите шаг 4, убедившись, что находитесь в
папке с `requirements.txt` — проверить можно командой `dir`.

**Не хватает памяти, сервер тормозит**

Windows Server съедает 1–1,5 ГБ из ваших 2 ГБ. Боту нужно немного, но
если станет тесно — Linux на том же тарифе оставит почти всю память
свободной.
