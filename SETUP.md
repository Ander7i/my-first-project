# Подключение бота к группе

Пошаговая инструкция от нуля до работающего бота в вашей группе.
Занимает 20–30 минут. Ничего знать заранее не нужно.

Если что-то не получается, в конце есть раздел **Если не работает** с
разбором всех частых случаев.

---

## Что понадобится

- Телеграм на телефоне или компьютере.
- Сервер или компьютер, который будет работать постоянно. Бот живёт,
  пока запущен процесс: закроете окно — бот перестанет отвечать.
- Права администратора в группе, куда подключаете.

---

## Шаг 1. Создать бота

1. Откройте в Телеграме [@BotFather](https://t.me/BotFather) и нажмите
   **Start**.
2. Отправьте `/newbot`.
3. Он спросит имя — это то, что люди видят в заголовке чата. Например
   `Проверки банков`. Может быть на русском и с пробелами.
4. Потом спросит username — он должен заканчиваться на `bot` и быть
   уникальным. Например `bank_checks_2026_bot`. Только латиница, цифры и
   подчёркивания.
5. В ответ придёт токен — длинная строка вида
   `7123456789:AAEhBP0abcdefGHIJklmnoPQRstuVWxyz12`.

**Токен — это пароль от бота.** Кто его знает, может писать от имени
бота кому угодно. Не пересылайте его и не публикуйте. Если утёк —
`/revoke` в @BotFather, и токен сменится.

Скопируйте токен, он нужен на шаге 3.

---

## Шаг 2. Установить бота на сервер

Нужен Python 3.11 или новее. Проверить: `python3 --version`.

```bash
git clone https://github.com/Ander7i/my-first-project.git
cd my-first-project
python3 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

Если команда `git` не найдена — поставьте git, либо скачайте архив с
GitHub кнопкой **Code → Download ZIP** и распакуйте.

---

## Шаг 3. Вписать токен

```bash
cp .env.example .env
```

Откройте `.env` любым редактором (`nano .env`) и впишите токен:

```
BOT_TOKEN=7123456789:AAEhBP0abcdefGHIJklmnoPQRstuVWxyz12
ADMIN_IDS=1
```

`ADMIN_IDS` пока оставьте `1` — заполним на следующем шаге.

В `nano` сохранить: `Ctrl+O`, `Enter`, затем `Ctrl+X`.

---

## Шаг 4. Узнать свой ID и стать администратором

Запустите бота:

```bash
python -m bot
```

В логе должно появиться `Бот @ваш_бот запущен`. Предупреждения про
`GROUP_CHAT_ID` и `SUPPORT_CONTACT` — нормально, их заполним дальше.

Теперь найдите своего бота в Телеграме по username и:

1. Нажмите **Start**.
2. Отправьте `/myid`.
3. Бот ответит числом — это ваш ID.

Остановите бота (`Ctrl+C`), впишите ID в `.env`:

```
ADMIN_IDS=123456789
```

Если администраторов несколько — через запятую, без пробелов:
`ADMIN_IDS=123456789,987654321`. Каждый из них должен сам отправить боту
`/myid`, чтобы узнать свой номер.

---

## Шаг 5. Добавить бота в группу администратором

Это ключевой шаг. Без прав администратора бот не сможет писать в группу.

**На телефоне:**

1. Откройте группу → нажмите на её название сверху.
2. **Изменить** (карандаш) → **Администраторы** → **Добавить
   администратора**.
3. Найдите своего бота по username и выберите его.
4. Включите права:
   - **Отправка сообщений** — обязательно;
   - **Удаление сообщений** — по желанию;
   - остальное не нужно.
5. Сохраните (галочка сверху).

**На компьютере:**

1. Откройте группу → название группы сверху → **Manage group**.
2. **Administrators** → **Add Administrator** → выберите бота.
3. Оставьте **Send Messages** и сохраните.

> Если бота нет в поиске — сначала добавьте его в группу обычным
> участником (**Добавить участников** → найдите по username), а потом
> повысьте до администратора.

---

## Шаг 6. Узнать ID группы

Запустите бота снова (`python -m bot`) и напишите **в группе**:

```
/chatid
```

Бот ответит числом вида `-1001234567890`. **Минус в начале
обязателен** — это часть ID, не опечатка.

Остановите бота и впишите в `.env`:

```
GROUP_CHAT_ID=-1001234567890
```

---

## Шаг 7. Разрешить боту видеть вопросы участников

По умолчанию Телеграм показывает боту в группе **только** команды и
сообщения, где его упомянули через `@`. Чтобы он сам отвечал на вопросы
вроде «а сколько платят?», это нужно отключить.

1. Откройте [@BotFather](https://t.me/BotFather).
2. Отправьте `/setprivacy`.
3. Выберите своего бота.
4. Нажмите **Disable**.

> **Disable** здесь означает «отключить режим приватности», то есть
> разрешить боту видеть сообщения. Название сбивает с толку, но нужен
> именно **Disable**.

Если пропустить этот шаг, бот будет отвечать только когда его упомянут
через `@` или ответят на его сообщение. Всё остальное работает так же.

**Важно:** после смены настройки удалите бота из группы и добавьте
заново — Телеграм применяет её только при новом входе в чат.

---

## Шаг 8. Указать контакт для ссылок

Если вы выдаёте партнёрские ссылки лично, бот должен знать, к кому
отправлять людей. Впишите в `.env` свой ник:

```
SUPPORT_CONTACT=@ваш_ник
```

Ник можно посмотреть в Телеграме: **Настройки → Имя пользователя**. Если
его нет — задайте, иначе кнопка «Написать за ссылкой» работать не будет.

---

## Шаг 9. Запустить и опубликовать набор

```bash
python -m bot
```

В личке с ботом отправьте `/admin` — должна появиться панель с цифрами.
Если вместо неё «Эта команда только для администраторов», значит
`ADMIN_IDS` заполнен неверно: вернитесь к шагу 4.

Теперь отправьте боту `/post` — он опубликует в группе объявление о
наборе с кнопкой «Хочу участвовать».

Всё, бот работает. Люди нажимают кнопку, заполняют анкету и попадают в
базу.

---

## Шаг 10. Создать первое задание

В личке с ботом: `/newtask`. Бот проведёт по шагам:

1. **Продукт** — кнопками.
2. **Проверка** — кнопками, из каталога.
3. **Банк или МФО** — текстом.
4. **Город** — спросит только для выездных проверок.
5. **Оплата** — число в рублях.
6. **Срок** — дата. Понимает `30.10.2026`, `30.10`, `30 октября`,
   `через 7 дней`, `завтра`.
7. **Сколько исполнителей** — число.
8. **Ссылка** — вставьте партнёрскую ссылку, и бот выдаст её сам. Или
   нажмите «Выдам сам», если ссылки персональные.
9. **Детали** — адрес отделения, какой вопрос задать поддержке, какой
   тариф оформлять. Шаги и чек-лист подставятся из каталога сами.

Перед созданием бот покажет задание и **сколько исполнителей под него
подходит**. Если ноль — значит в базе нет людей с таким продуктом или
городом.

## Чтобы бот работал постоянно

Пока вы запускаете его командой в терминале, он остановится, как только
вы закроете окно. Для постоянной работы на Linux-сервере:

Создайте файл `/etc/systemd/system/shopper-bot.service`:

```ini
[Unit]
Description=Bank mystery shopper bot
After=network.target

[Service]
WorkingDirectory=/путь/к/my-first-project
ExecStart=/путь/к/my-first-project/.venv/bin/python -m bot
Restart=always
RestartSec=5
User=ваш_пользователь

[Install]
WantedBy=multi-user.target
```

Замените оба пути и имя пользователя на свои (`pwd` покажет текущий
путь, `whoami` — имя пользователя).

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now shopper-bot
sudo systemctl status shopper-bot        # проверить, что работает
sudo journalctl -u shopper-bot -f        # смотреть логи живьём
```

Теперь бот поднимается сам при перезагрузке сервера и перезапускается,
если упадёт.

## Проверка, что всё настроено

Пройдите этот список — он ловит почти все проблемы:

- [ ] `/admin` в личке показывает панель с цифрами
- [ ] `/chatid` в группе отвечает числом с минусом
- [ ] `/post` публикует объявление в группе
- [ ] кнопка «Хочу участвовать» открывает бота
- [ ] анкета проходится до конца и `/profile` показывает заполненное
- [ ] `/catalog` открывает список продуктов
- [ ] `/newtask` создаёт задание и показывает число подходящих
- [ ] задание приходит в личку исполнителю
- [ ] в группе на вопрос «сколько платят?» бот отвечает сам (шаг 7)

## Если не работает

**Бот не отвечает вообще**

Проверьте, запущен ли процесс: в терминале должен идти лог. Если
написано `Telegram отклонил токен` — токен неверный, перепроверьте
`BOT_TOKEN` в `.env`, он копируется целиком вместе с цифрами до
двоеточия.

**«Эта команда только для администраторов»**

`ADMIN_IDS` не совпадает с вашим ID. Отправьте боту `/myid` и сверьте
число. Частая ошибка — лишние пробелы или кавычки в `.env`.

**Бот не пишет в группу**

Он не администратор либо без права отправки сообщений. Вернитесь к
шагу 5. Проверить можно командой `/post`: бот покажет точную ошибку от
Телеграма.

**`/chatid` в группе не отвечает**

Бот не добавлен в эту группу или остановлен. Если добавлен и запущен —
проверьте, что отправляете команду именно в группе, а не в личке.

**Бот не реагирует на вопросы в группе, только на команды**

Не сделан шаг 7, либо сделан, но бот не был заново добавлен в группу.
Удалите его из группы и добавьте снова.

**`api.telegram.org` недоступен с сервера**

Бывает на части российских хостингов. Впишите в `.env` прокси:

```
PROXY_URL=http://user:pass@host:3128
```

Поддерживаются HTTP и SOCKS5 (`socks5://...`).

**Ошибка `ModuleNotFoundError: No module named 'aiogram'`**

Не активировано окружение. Выполните `source .venv/bin/activate` и
повторите, либо запускайте полным путём:
`.venv/bin/python -m bot`.

**Задание никому не пришло**

Бот перед созданием показывает число подходящих исполнителей. Если там
ноль — в базе нет людей, у которых в анкете отмечен этот продукт и
совпадает город. Для выездных проверок город обязателен, для
дистанционных не важен. Разослать повторно: `/tasklist` → задание →
«Разослать исполнителям».

**Люди жалуются, что не видят заданий**

Пусть проверят `/profile`: возможно, в анкете не отмечен нужный продукт.
Изменить — `/survey`.
